# Ludoforge Backlog

Este directorio contiene las tareas del proyecto Ludoforge, organizadas por fase.

## Fases

- **Fase 0 — Cimientos** (LF-001 a LF-012)
- **Fase 1 — Núcleo jugable: Godot + plataformas 2D** (LF-020 a LF-032)
- **Fase 2 — Multiagente real, MCP y hosts** (LF-040 a LF-050)
- **Fase 3 — 2D completo, adaptador Web, generación real de assets** (LF-100 a LF-108)
- **Fase 4 — 3D** (LF-120 a LF-127)
- **Fase 5 — Mundo abierto y simulación** (LF-140 a LF-147)
- **Fase 6 — Publicación y ecosistema** (LF-160 a LF-168)

## Estado de las tareas

Las tareas se mueven mediante el flujo: backlog → ready → in_progress → in_review → verified → done

Las ramas blocked y rejected manejan bloqueos y rechazos respectivamente.

Ver `docs/STATUS.md` para el estado actual del proyecto.
